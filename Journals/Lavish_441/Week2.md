# Week 2 -- Requirement Analysis and Project Planning

## Objective

The objective of this week was to move from the initial project idea
towards a clearer understanding of the system requirements and its
functional modules.

## Activities Completed

-   Discussed the requirements of the proposed academic platform with
    the team.
-   Identified the main users and the functions they would need from the
    system.
-   Broke the project into smaller functional modules.
-   Discussed the expected behaviour of Login, Notes, Classroom, PYQs,
    Create Class, and Join Class.
-   Distinguished between the overall system requirements and individual
    module requirements.
-   Reviewed the requirements with the team to remove unclear or
    unnecessary functionality.
-   Started organizing the requirements so that they could later be
    represented through UML models.
-   Contributed to preparing the Project Proposal.

## Requirement Analysis

The project requirements were considered from the user's point of view.
The discussion focused on what the system should provide rather than how
the system would be implemented.

The main functional areas identified were:

-   User Login
-   Access to Notes
-   Access to Previous Year Questions
-   Classroom functionality
-   Creating a Class
-   Joining a Class

The requirements identified in this stage were used as a foundation for
later modelling and implementation.

## My Contribution

I participated in requirement discussions and helped break the overall
platform into manageable functional areas. I also contributed to
reviewing the proposed functionality and preparing the Project Proposal.

## Software Engineering Learning

This week's work helped me understand the importance of requirements
before implementation. I also studied how requirements can be documented
and later transformed into models that communicate system behaviour to
the development team.

The work was connected with requirements engineering, requirement
analysis, and the initial stages of software design.

## Outcome

The project requirements and module structure became clearer during this
week. The Project Proposal was completed using the project objectives,
requirements, and planned functionality.
