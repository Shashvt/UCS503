# Week 1 -- Project Idea, Software Process and Initial Requirements Study

## Objective

The objective of this week was to finalize the project idea and
understand the project from a Software Engineering perspective before
starting detailed design and implementation.

## Activities Completed

-   Discussed and finalized the project idea with the team.
-   Conducted initial research about the selected platform and its
    purpose.
-   Identified the main problem that the project aims to address.
-   Discussed the expected users and the major functions they would
    require.
-   Identified the initial modules of the platform, including Login,
    Notes, Classroom, PYQs, Create Class, and Join Class.
-   Studied how the project could be approached through a software
    development process.
-   Reviewed different software process models such as Waterfall,
    Iterative, Incremental, and Evolutionary models to understand how
    software development can be organized.
-   Discussed the importance of software evolution and the need to
    consider future changes while planning the project.
-   Considered basic software quality and sustainability aspects while
    discussing the project.

## Initial Requirement Identification

The initial requirements identified from the project discussion
included:

-   A user should be able to log in to the platform.
-   Users should be able to access academic notes.
-   Users should be able to access Previous Year Questions.
-   Users should be able to access classroom-related functionality.
-   Users should be able to create or join a class.

These requirements were kept as an initial understanding and were
planned to be refined in the following weeks.

## My Contribution

## Software Engineering Concepts Covered

This week's work was connected with:

-   Introduction to Software Engineering
-   Software characteristics and software evolution
-   Software process models
-   Problem identification and initial requirements
-   Software sustainability and green software considerations

## Outcome

The project idea and its initial scope were finalized. The team
developed a common understanding of the problem, expected functionality,
and major modules. This provided the base for more detailed requirement
and module planning in Week 2.
