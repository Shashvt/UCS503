# Week 3 – Frontend Implementation and Login Form Validation

## Objectives

The main objective of this week was to begin the basic frontend implementation of the project and improve the Login page by implementing client-side form validation.

## Activities Completed

- The basic frontend implementation of the project was started.
- The initial frontend structure and user interface were developed by the other team members.
- Worked on the Login page functionality.
- Implemented form validation using JavaScript.
- Added validation checks for the input fields in the Login form.
- Tested the validation to ensure that invalid or incomplete input is handled appropriately.

## My Contribution

My main contribution during this week was implementing JavaScript-based form validation for the Login page.

The validation was designed to check the user's input before the form is submitted. This helps prevent empty or invalid form data from being submitted and provides appropriate feedback to the user.

## Technical Implementation

JavaScript was used to implement the client-side validation.

The validation process included:

- Checking whether required fields were filled.
- Validating the entered input before submission.
- Displaying appropriate validation messages when the input was invalid.
- Allowing the form to proceed when the required validation conditions were satisfied.

## Testing

The Login form was tested with different types of inputs to verify that the validation worked correctly.

Test cases included:

- Empty input fields.
- Partially completed form.
- Invalid input.
- Valid input.

## Outcome

By the end of the week, the basic frontend implementation had been started by the team, and JavaScript form validation was successfully implemented for the Login page. This provided better input handling and improved the basic functionality of the frontend.
